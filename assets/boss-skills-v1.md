# Boss skill animation artwork v1

Generated with the built-in imagegen tool using the current down-facing boss gait sheets as design/style references. Six transparent PNGs in this directory: `{warlord,pyro,necro}-skill-{left,right}-v1.png`. Each has nine row-major action poses, including a neutral recovery pose. Metadata generation only reads artwork; PNG alpha is preserved.

Warlord axe-slam, Pyromancer fire-fan cast and Necromancer summon gestures use the existing 0.78-second simulation clock. The side is latched when the skill triggers. Effects, telegraph, damage, cooldowns, movement and inherited abilities retain their previous timing. Art shows anticipation and recovery without delaying gameplay events. Melee attack art remains the earlier sheet. Left/right skills use separate authored front three-quarter views rather than eight directional casts. Cached at 2× display body height; only selected-boss sources decode during the gauntlet. Physical iPhone Safari testing is still outstanding.

Rebuild: `python prepare-boss-skills.py`, `node integrate.cjs`, `node make-boss-skill-preview.cjs`. Review: `boss-skill-review.html`. Test: `node test-boss-skills.cjs` (also in full test suite).

Entire character faces diagonally toward screen right, front three-quarter view, SAME view all nine frames. Preserve anatomical hand continuity; do NOT mirror the reference wholesale. 3 columns x 3 rows of exactly NINE full-body sprites in equal cells, chronological row-major reading order. Axe-slam ability: 1 ready two-hand axe guard, 2 pull axe back, 3 raise above shoulders, 4 overhead apex, 5 forceful downward slam, 6 low follow-through, 7 lift axe back, 8 ease toward guard, 9 identical neutral guard to frame1. Both feet remain planted throughout. No ground cracks, no magic floor effect. Same character body scale, head location and planted boot baseline in all nine cells, with generous 15% transparent gutters so axe/staff never crosses cell boundaries. Full boots, horns, weapon always visible. Animate arms, weapon, cape and slight torso action with distinct coherent poses, no walking or foot shuffle. Match the reference black outlines, gold trim, compact proportions and pixel texture, not painterly. No text, grid, labels, backdrop or drop shadows. All nine poses are one continuous 0.78 second action with return to neutral.
