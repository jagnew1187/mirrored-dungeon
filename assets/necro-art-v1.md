Created using built-in image generation. Source files: `necro-materials-v1.png` and `necro-props-v1.png`. Embedded into the standalone HTML by `integrate.cjs`; no runtime asset downloads.

`necro.js` caches room canvases, material tiles and scaled sprites. Atlas rectangles are fitted to actual sprite silhouettes. Ghost light uses one cached radial texture with animated opacity. All images use nearest-neighbor sampling. Rune plates share the existing 48px footprint and warning/active/recovery timing, with colored outlines and no exclamation overlay. Active runes retain their existing slowing effect. Coffins use intact, cracked and destroyed art; destroyed props are passable. The ceremonial path is anchored to the world to prevent texture swimming while scrolling. Generated textures are not guaranteed mathematically seamless.
