# Boss eight-direction movement v2

Warlord, Pyromancer and Necromancer now have eight independently authored directional sheets each. Each 3×3 sheet contains eight walk poses and a planted standing pose in cell nine. Original boss identity sheets are preserved in boss-reference/.

Runtime uses actual movement distance, stable 45-degree facing sectors and boot anchors. Strides: Warlord 80 world pixels; Pyromancer/Necromancer 64. Existing speeds, attacks, skills, damage, inheritance and collision remain unchanged. Attack and skill artwork retains the previous side-view sheets. Selected boss textures preload during the gauntlet and cache at twice their displayed body resolution; source Image objects are released. No runtime mirroring of walk/stand equipment.

Regenerate metadata with `python prepare-boss-gaits.py`, build with `node integrate.cjs`, and create the comparison page with `node make-boss-preview.cjs`. Source PNGs are unchanged by metadata preparation. `test-boss-gaits.cjs` checks desktop/mobile AI pursuit, all poses, standing, anchors, caching and legacy action frames. Mobile Chromium emulation is covered; physical iPhone Safari still needs device testing.
