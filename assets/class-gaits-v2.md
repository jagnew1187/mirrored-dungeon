# Wizard / Rogue eight-direction movement v2

Generated with the built-in imagegen tool, using the previous Mage and Rogue sheets as identity references. Each new 3×3 sheet has eight walking poses and a bottom-right planted standing pose. All eight views are independently authored, with no runtime mirroring for walking/standing. The existing class identifier is mage (Wizard).

`class-gait-art.json` maps assets; `class-gait-frames-v2.json` stores measured rectangles, hood/body registration and ground baselines. `prepare-class-gaits.py` reads alpha and hood colors, excludes detached neighboring-row pixels, and fits bounds without modifying source PNGs. Alpha is used for visual frame isolation only, never gameplay collision.

## Integration

`class-gait-renderer.js` decodes each source into a compact atlas at approximately twice game-body resolution, using nearest-neighbor sampling, and releases source-image references. Original art remains intact; cached frames carry equivalent transformed anchors. Runtime pixel memory is checked to be lower than the source sheets. All classes now use the existing eight-sector movement selector with a five-degree overlap. Wizard/Rogue stride distances are 84/92 world pixels per full two-step cycle, replacing accumulated slowdown factors for their old art. Gameplay travel speeds, attack/skill damage/timing, collision, match timing, rivals, rewards and Knight art are unchanged. Attacks/skills retain existing side-view art, including its existing directional handling; this pass updates walking and standing.

Use heroes-walk-review.html for the same cached rendering as the game, with class/view, speed, pause, standing and pose controls. Body scale stays at the smaller hero size. Source poses have sprite-based contact timing rather than a skeletal IK solver; exact pixel-perfect foot locking on every diagonal is not claimed.

## Corrections and validation

Wizard front diagonals retain the staff in the right hand at screen-left; rear views retain it on the supporting right arm at screen-right. The southwest facing direction and northwest staff arm were corrected after visual inspection. Rogue southwest orientation was corrected with the authored left-facing sheet as a reference. Daggers remain visibly held in both hands. Sprite and gameplay tests cover eight views, normalized movement, phase continuity, standing, cached bounds, boot baselines, non-mirroring, source-memory reduction, reduced-motion walking, preview controls, existing routes and camp companions. Desktop Chromium mobile layouts are tested; a physical iPhone Safari run remains a device check.
