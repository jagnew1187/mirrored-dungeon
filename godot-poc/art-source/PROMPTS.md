Built-in official imagegen mode. One availability-check request succeeded (woodland); three subsequent production requests supplied buildings, enemy poses and hero poses. No CLI/API fallback, commercial download or external asset library was used. All outputs were copied into this directory. Runtime processing is reproducible with `../tools/pass07_art.py`; supplied parent-repository artwork is never edited.

## Integration review

Outputs were inspected, cropped, thresholded and scaled locally using the user-authorized pixel-art processing workflow. Source crops/roots are recorded in `../assets/pass07/manifest.json`. The hero sheet did not fully obey weapon direction, so only its weapon-arm layers were rigged locally; bodies/faces retain their directional views. Enemy crops required neighboring-fragment removal. Generated poses are not full animation cycles. These limitations are recorded in the production guide and Pass 07 report.
