# Mirrored Dungeon — Pass 11.5 RC7

This is the current Godot game source. Open `project.godot` with Godot 4.7.2 and run the main scene. Import assets before exporting with the included Web preset.

RC7 includes responsive iPhone HUD controls, scrollable character creation with animated class cards, and target-based touch auto-attack. Select an enemy and tap Attack to engage; tap Attack again or empty ground to disengage. Desktop controls and existing campaign saves are preserved.

Validation: 2,916 native and 449 browser assertions passed. Physical iPhone keyboard and touch-comfort checks remain device acceptance tasks.

Only runtime source, required assets, asset attribution, and export configuration are included. Generated web exports, archives, tests, screenshots, reports, local saves, caches, and LAN certificates are kept out of this upload. See ASSETS.md for attribution.
